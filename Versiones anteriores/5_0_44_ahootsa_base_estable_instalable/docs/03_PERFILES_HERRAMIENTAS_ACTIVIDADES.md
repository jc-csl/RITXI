# Perfiles y herramientas

El perfil recomendado `ahootsa_realtime_es` activa herramientas estables y evita duplicados.

No se activan en `tools.txt` los alias duplicados: `explorar_imagen`, `listar_actividades_comunicacion`, `iniciar_actividad_comunicacion`, `play_emotion_with_audio`.

Las herramientas existen en la carpeta `tools` para compatibilidad, pero no se ofrecen al modelo salvo que se añadan manualmente a un perfil.
