# Actividades de comunicación por niveles — Ahootsa 7.0.23

Las actividades principales de comunicación son cuatro y existen en tres niveles:

1. **Saludar**.
2. **Pedir comida**.
3. **Mantener turnos**.
4. **Conversar**.

La persona puede pedirlas por nombre o por número.

## Pregunta inicial recomendada

```text
¿Qué nivel quieres trabajar: fácil, intermedio o avanzado?
Podemos practicar saludar, pedir comida, mantener turnos o conversar.
```

## Nivel fácil

Actividades muy guiadas, con dos opciones y frases modelo.

1. **Saludar**: responder a un saludo con una frase corta.
2. **Pedir comida**: pedir agua o comida con una frase sencilla.
3. **Mantener turnos**: esperar, escuchar y decir “ahora me toca”.
4. **Conversar**: responder una pregunta sencilla y hacer otra.

## Nivel intermedio

Actividades con frases más completas y pequeñas decisiones.

1. **Saludar y preguntar cómo está**.
2. **Pedir comida en una cafetería**.
3. **Mantener turnos en una conversación**.
4. **Conversar sobre un tema cotidiano**.

## Nivel avanzado

Actividades con contexto social, matices y conversación más larga.

1. **Saludar según la situación**.
2. **Pedir comida con cambios o preferencias**.
3. **Mantener turnos en grupo**.
4. **Conversar manteniendo el tema**.

## Uso por voz

Ejemplos:

```text
actividades de comunicación
actividades fáciles
actividades intermedias
actividades avanzadas
quiero practicar saludar
quiero pedir comida
vamos a mantener turnos
quiero conversar
inicia la actividad dos intermedia
```

## Nota técnica

Estas actividades **no usan Ollama**. Son herramientas locales de Ahootsa con respuesta directa para reducir latencia.
