Actividades y juegos disponibles en Ahootsa

ACTIVIDADES DE COMUNICACIÓN

Tienen 3 niveles:
- Fácil.
- Intermedio.
- Avanzado.

Las 4 actividades principales son:
1. Saludar.
2. Pedir comida.
3. Mantener turnos.
4. Conversar.

Ejemplos por voz:
- "actividades de comunicación"
- "actividades fáciles"
- "actividades intermedias"
- "actividades avanzadas"
- "quiero practicar saludar"
- "quiero pedir comida"
- "vamos a mantener turnos"
- "quiero conversar"
- "inicia la actividad dos intermedia"

Estas actividades no usan Ollama. Son locales y deben responder rápido.


Juegos Memory visuales:
- 4 parejas.
- 8 cartas grandes.
- Dorso azul.
- Número blanco grande en cada carta.
- En pantalla solo aparecen cartas.
- El tiempo de visualización se configura en memory_timing_config.json.
- El robot guía el ritmo y puede dar pistas.

1. animales
2. ciudades
3. alimentos

Uso por voz:
- "quiero el juego de animales"
- "quiero el juego de ciudades"
- "quiero el juego de alimentos"
- "levanta la 1 y la 5"
- "dame una pista"

Regla: si el usuario falla, el robot debe reaccionar una sola vez por intento, no repetir la misma reacción.

Al terminar el juego, Ahootsa felicita, reinicia y pregunta si quiere jugar otra vez o hacer otra actividad.


Bailes y emociones:
- Usa nombres en español.
- Internamente se lanzan los recursos oficiales JSON/OGG.

Ejemplos:
- "lista de bailes"
- "haz baile uno"
- "haz baile dos"
- "haz baile tres"
- "haz un saludo"
- "haz calma"
- "haz celebración"
- "haz algo eléctrico"
